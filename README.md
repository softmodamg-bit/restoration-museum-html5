# 반짝! 복원 미술관 — HTML5 Vertical Slice

밝고 캐주얼한 2.5D 벡터 아트로 만든 **미술품 복원 + 미술관 운영** HTML5 게임 프로토타입입니다.
기본 플레이와 저장은 외부 라이브러리나 네트워크 요청 없이 폴더만으로 실행됩니다. 선택 기능인 공용 랭킹만 Google Apps Script 웹 앱에 연결합니다.

## 바로 실행

### 가장 간단한 방법
`index.html`을 더블클릭합니다.

### 로컬 서버로 실행
```bash
python -m http.server 8080
```
브라우저에서 `http://localhost:8080`을 엽니다.

## 현재 구현된 기능

- 작품 500종: 14개 재료군의 도자기, 회화, 금속, 직물, 유리, 사진, 책, 벽화 등
- 작품마다 시대·작가·유형·출처·문화적 가치·짧은 사연 수록
- 작품명·재료·복원 상태 검색과 24개씩 점진 표시
- 작품별로 다른 복원 단계와 도구 선택
- 조명 전환 손상 조사, 자외선 보수 흔적 조사, 시험구 안전/중단 판정, 결 따라 방향 전환, 파편 건식 맞춤, 환경 안정화, 미세량 홀드·놓기, 처리 절차 판단, 접착제 점적, 식별 가능한 보색, 접합면 정렬, 세척 강도 판단, 처리량 나누기, 받침 무게 잡기의 14종 복원 미니게임
- 14종 미니게임마다 정식 작업명, 쉬운 말 풀이, 작품에 생기는 변화와 예방되는 손상을 함께 안내
- 작품별 실제 복원 단계 4~5개에 14종 미니게임을 재료·도구 성격에 맞춰 배정
- 잘못된 도구 선택 시 위험도와 정확도 변화
- 플레이어 이름과 미술관 이름을 정하는 관장 취임식, 윤슬 창에서 명패 수정과 부적절한 이름 차단
- 비서 윤슬의 화면별 안내, 우선 과제, 운영 현황 브리핑
- 새 게임의 작품 이야기 → 복원 5단계 → 전시 → 개관 → 운영 보고를 잇는 첫 로테이션 튜토리얼
- 관장이 된 이유와 손상 컬렉션의 기원을 밝히는 프롤로그
- 전시 매력도 100마다 열리는 10개 본편 챕터, 매력도 1,000 엔딩, 이후 300 간격으로 매력도 2,500까지 이어지는 후일담 5편
- 해금·잠금·다음 목표를 한눈에 보고 지난 이야기를 다시 여는 스토리 아카이브
- 정확도 80%부터 B·A·S·S+ 등급에 따라 별도 코인·평판이 붙는 정밀 복원 보상
- 다른 화면에서는 멈추는 복원 타이머와 정확도 80% 이상부터 지급되는 시간 가산점·코인 보너스
- 전시관 배치, 일일 관람객·수입 계산과 관람객별 동전 수익 팝업
- 전시 작품 앞에서만 관람객이 작품 시대·복원 방식·감상을 말하는 전시 말풍선
- 실제 개관 수입으로 충전되는 시설 예산과, 전시장 장면이 직접 변하는 시설 투자 12종
- 조명, 키오스크, 라운지, 정원, 카페, 복원 스튜디오, 파사드, 대전시홀 등이 전시관에 직접 나타나는 단계별 공간 변화
- 14종 미니게임을 재료비·보상·실제 작품 기록과 분리해 골라 연습하는 보존 연습실
- 복원 처리 기록실
- 현재 세이브에서 공개 가능한 성과만 즉시 추출해 보내는 원클릭 관장 랭킹 제출
- 복원 정확도·시간·위험도와 누적 개관 수입·관람객·이야기 완주 속도를 서버에서 재계산하고 플레이어별 최고 기록만 남기는 Google Apps Script 랭킹 템플릿
- 서버 주소가 없어도 제출 화면과 계산 결과를 확인할 수 있는 공모전 심사용 데모 모드
- localStorage 자동 저장
- 서버 없는 JSON 저장 파일 내보내기·불러오기
- 사용자 입력으로 시작하는 실시간 생성 Web Audio BGM과 WAV·Web Audio 이중 효과음
- 탭 숨김과 Alt+Tab·다른 프로그램 전환 시 BGM·복원 진행 일시정지, 복귀 시 설정에 따른 자동 재개
- 스토리 메뉴에서 확인하는 BGM 재생 상태, 음량 조절, 재생 테스트
- 모바일 반응형 UI와 reduced-motion 대응

## Codex에 처음 요청할 문장

`docs/CODEX_BRIEF.md`를 먼저 읽고, 현재 게임을 실행해 기능 회귀 테스트를 한 뒤 1단계 작업부터 진행해 줘. 기존 저장 데이터 호환과 모바일 터치 조작을 유지해 줘.

## 콘텐츠 추가 위치

기본 4종은 `js/game.js`, 확장 컬렉션은 `js/artworks-data.js`에서 관리합니다.

각 작품에는 다음 정보가 필요합니다.

- `id`, `title`, `material`, `unlockRep`
- 비용·보상·전시 매력도
- 손상 설명, 완료 요약, 윤리 노트
- 시대·작가·유형·출처·문화적 가치·작품 이야기
- `steps`: 단계명, 안내문, 올바른 도구, 상태 기록, 타깃 좌표
- 색상·문양·구도 시드를 이용한 작품별 SVG 그림

## 주의

현재 버전은 공모전·피칭용 **플레이 가능한 버티컬 슬라이스**입니다. 확장 작품과 해설은 게임용 가상 콘텐츠이며 실존 작품 정보가 아닙니다. 첨부 카탈로그의 권리 위험도 `고` 후보 27점은 플레이가 잠겨 있습니다. 실제 서비스 빌드 전에는 아트 에셋 분리, 권리 검토, QA, 접근성 테스트, 저장 마이그레이션, 학예·보존 전문가의 콘텐츠 검수 작업이 필요합니다.
