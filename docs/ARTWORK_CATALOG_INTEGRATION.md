# 첨부 미술품 후보 카탈로그 반영 기록

## 반영 원칙

- 첨부된 `ARTWORK_CATALOG.md`는 완성 이미지 목록이 아니라 재료·보존 과제를 위한 연구 후보로 사용한다.
- 원작 이미지, 구도, 인물 배치, 식별 가능한 핵심 형상을 게임에 복제하지 않는다.
- 게임에는 밝고 캐주얼한 오리지널 SVG 변주와 가상 작품명·가상 작가만 표시한다.
- 위험도 `고` 후보 27점은 컬렉션 수에는 포함하되 `아트 방향 권리 검토 중`으로 잠근다.
- 실제 화학물질의 배합이나 농도는 게임 조작으로 제공하지 않는다.
