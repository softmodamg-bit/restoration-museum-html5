# 전체 텍스트 검수본 01 · 작품 1~100

각 작품의 화면 표시용 설명, 이야기, 손상, 복원 요약, 윤리 설명과 복원 단계를 담습니다.

### 001. 색동 달항아리

- 작품 ID: `moon-jar`
- 재질: 도자기
- 분류 문구: 첫 소장품
- 시대: 동시대 전통 재해석
- 작가: 도예가 한가람 (가상)
- 작품 종류: 색띠 장식 백자 항아리
- 어디서 왔나요?: 해오름 도요 기증
- 작품 가치: 전통 달항아리의 완전히 똑같지 않아도 편안한 균형에 현대적인 색띠를 더해 전통 공예가 오늘의 감각으로 이어지는 방식을 보여 줍니다.
- 작품 이야기: 한가람은 서로 다른 흙 두 덩이를 이어 붙이는 달항아리 제작법을 ‘두 개의 마음이 하나의 둥근 풍경이 되는 일’이라고 기록했습니다. 이 작품은 작가가 지역 축제의 색동천에서 영감을 받아 만든 첫 번째 실험작입니다.
- 손상 설명: 먼지와 붙인 부분이 벌어지고 작은 빈 곳이 함께 보입니다.
- 복원 완료 요약: 깨진 선을 숨기기보다 구조를 튼튼하게 잡고 비어 있는 부분만 꼭 필요한 만큼 보완했습니다.
- 복원 윤리 설명: 좋은 복원은 새것처럼 만드는 일이 아니라, 원본을 더 손상시키지 않으면서 읽을 수 있게 돕는 일입니다.
- 가상 작품 여부: 게임을 위해 만든 가상 작품

#### 복원 단계

1. **손상 조사**
   - 안내: 금과 빈 곳 위치를 확대 관찰하세요.
   - 상태 기록: 조명 아래에서 금 방향과 파편 이탈 범위를 먼저 기록합니다.
   - 도구: 확대경
2. **안전성 시험**
   - 안내: 접착 전 작은 시험 자리를 확인하세요.
   - 상태 기록: 표면 장식과 유약이 처리 재료에 반응하지 않는지 시험합니다.
   - 도구: 작은 시험용 면봉
3. **파편 접합**
   - 안내: 맞닿는 파편 경계를 따라 접합하세요.
   - 상태 기록: 나중에 다시 손볼 수 있는 재료를 꼭 필요한 만큼만 써서 구조를 튼튼하게 잡아 줍니다.
   - 도구: 나중에 다시 뗄 수 있는 접착제
4. **빈 곳 보완**
   - 안내: 비어 있는 작은 빈 곳만 메워 주세요.
   - 상태 기록: 원래 모습을 짐작해 지나치게 채우지 않고 구조에 필요한 범위만 보완합니다.
   - 도구: 작은 틈 메움 주걱
5. **구별되는 복원 색 고르기**
   - 안내: 보완부의 색을 주변과 부드럽게 연결하세요.
   - 상태 기록: 가까이에서는 복원한 곳을 구별할 수 있도록 필요한 부분만 색을 맞춥니다.
   - 도구: 복원 색 붓

### 002. 봄빛 화조도 족자

- 작품 ID: `spring-scroll`
- 재질: 종이·채색
- 분류 문구: 고운 기록
- 시대: 1920년대 민화 재해석풍
- 작가: 채색화가 윤매화 (가상)
- 작품 종류: 종이 바탕 먹과 색으로 그린 그림 족자
- 어디서 왔나요?: 다정헌 가문에서 맡김
- 작품 가치: 화조도의 좋은 일을 바라는 상징과 근대기 그림 물감 사용, 그림을 족자로 꾸미는 방식을 한 작품에서 살펴볼 수 있는 생활문화 자료입니다.
- 작품 이야기: 윤매화가 어린 딸의 첫 봄나들이를 기념해 그린 작품으로 전해집니다. 새의 시선이 화면 밖을 향하는 것은 아직 오지 않은 계절을 기다린다는 뜻을 담은 작가의 개인적인 표식입니다.
- 손상 설명: 접힘 변형, 얼룩, 가장자리 찢김이 확인됩니다.
- 복원 완료 요약: 수분에 민감한 채색을 시험한 뒤 간접 가습과 보존용 종이 지지로 안정화했습니다.
- 복원 윤리 설명: 종이는 물에 민감하고 그림 물감마다 반응이 다릅니다. 전체 세척보다 색별 시험과 작은 범위 처리가 먼저입니다.
- 가상 작품 여부: 게임을 위해 만든 가상 작품

#### 복원 단계

1. **재료 반응 조사**
   - 안내: 색과 종이의 민감한 지점을 찾으세요.
   - 상태 기록: 번짐 가능성이 있는 채색과 과거 보수 흔적을 구분해 기록합니다.
   - 도구: 확대경
2. **색 묻어남 시험**
   - 안내: 색별 시험 지점을 가볍게 확인하세요.
   - 상태 기록: 물에 녹는 그림 물감이 묻어나지 않는지 작은 지점에서 확인합니다.
   - 도구: 작은 시험용 면봉
3. **간접 가습·평평하게 펴기**
   - 안내: 구겨진 부분을 천천히 펴 주세요.
   - 상태 기록: 직접 물을 대지 않고 습도를 서서히 전달해 접힌 자국을 천천히 폅니다.
   - 도구: 직접 물이 닿지 않는 가습 팩
4. **찢김 지지**
   - 안내: 찢어진 가장자리를 뒤에서 지지하세요.
   - 상태 기록: 얇은 보존용 종이와 알맞은 접착제로 찢김의 당기는 힘을 여러 곳으로 나눕니다.
   - 도구: 보존용 종이

### 003. 노을 정원의 산책

- 작품 ID: `sunset-painting`
- 재질: 유화
- 분류 문구: 인기 작품
- 시대: 1930년대 서정 회화풍
- 작가: 화가 박도윤 (가상)
- 작품 종류: 캔버스 유채
- 어디서 왔나요?: 은하 미술연구회 기증
- 작품 가치: 도시 외곽 공원이 대중의 새로운 여가 공간으로 자리 잡던 시기의 풍경과 빛에 대한 실험을 보여 줍니다.
- 작품 이야기: 박도윤은 같은 산책길을 열두 번 그렸지만 해 질 무렵의 두 인물이 함께 등장하는 작품은 이것뿐입니다. 뒷면에는 ‘돌아가는 길이 가장 오래 남는다’는 짧은 연필 메모가 있습니다.
- 손상 설명: 표면 먼지, 변색된 투명 보호막, 표면이 조금 떨어진 곳이 보입니다.
- 복원 완료 요약: 세척 시험을 거쳐 변색층을 작은 범위만 줄이고, 들뜬 채색층을 먼저 단단히 고정했습니다.
- 복원 윤리 설명: 투명 보호막 제거는 항상 정답이 아닙니다. 원래 표면과 그림 물감이 안전하다는 근거가 있을 때만 단계적으로 진행합니다.
- 가상 작품 여부: 게임을 위해 만든 가상 작품

#### 복원 단계

1. **층위 조사**
   - 안내: 투명 보호막과 채색층의 경계를 확인하세요.
   - 상태 기록: 표면 광택, 금, 과거 덧칠을 관찰해 처리 범위를 정합니다.
   - 도구: 확대경
2. **자외선으로 옛 수리 흔적 찾기**
   - 안내: 나중에 한 수리와 원본 재료가 자외선 아래서 어떻게 다르게 보이는지 구분하세요.
   - 상태 기록: 과거 덧칠·보수 니스와 원본층이 보이는 빛의 차이를 기록합니다.
   - 도구: 자외선(UV) 조사등
3. **표면 세척**
   - 안내: 먼지층을 부드럽게 제거하세요.
   - 상태 기록: 불안정한 채색층을 피하면서 느슨한 표면 오염만 제거합니다.
   - 도구: 부드러운 붓
4. **변색층 작은 범위 제거**
   - 안내: 시험이 끝난 부분만 천천히 처리하세요.
   - 상태 기록: 전체를 한 번에 벗기지 않고 작은 범위 단위로 반응을 확인합니다.
   - 도구: 오염 제거 겔
5. **표면이 떨어진 부분 복원한 곳의 색 맞추기**
   - 안내: 안정화된 작은 빈 곳을 연결하세요.
   - 상태 기록: 원본 위를 덮지 않고 비어 있는 부분 안에서만 다시 알아보기 쉽게 합니다.
   - 도구: 복원 색 붓

### 004. 구름무늬 청동거울

- 작품 ID: `bronze-mirror`
- 재질: 금속
- 분류 문구: 별빛 유물
- 시대: 19세기 후반 장식금속풍
- 작가: 금속공예가 최해원 (가상)
- 작품 종류: 주조 청동 거울
- 어디서 왔나요?: 별고을 생활사관에서 옮겨 받음
- 작품 가치: 쇳물을 틀에 부어 만든 뒤 새긴 구름무늬와 표면의 안정한 녹을 통해 장식 기술과 오랜 사용 환경을 함께 읽을 수 있습니다.
- 작품 이야기: 거울은 한 여행 상인이 길을 떠날 때마다 가족에게 맡겼다고 전해집니다. 가장자리의 네 점은 방향을 잊지 말라는 뜻으로 후대에 새겨진 것으로 추정되는 게임 속 설정입니다.
- 손상 설명: 표면에 녹색으로 녹슨 부분과 고르지 않게 녹슨 표면이 있습니다.
- 복원 완료 요약: 계속 번지는 녹 여부를 먼저 확인하고, 불안정한 부식물만 제거한 뒤 얇은 보호층을 적용했습니다.
- 복원 윤리 설명: 금속은 반짝이게 닦는 것보다 계속 번지는 녹을 멈추고 안정적인 표면을 남기는 일이 우선입니다.
- 가상 작품 여부: 게임을 위해 만든 가상 작품

#### 복원 단계

1. **계속 번지는 녹 조사**
   - 안내: 불안정한 부식 지점을 표시하세요.
   - 상태 기록: 색, 가루처럼 약해지는 현상, 들뜸을 관찰해 안정한 녹과 계속 번지는 녹을 구분합니다.
   - 도구: 확대경
2. **기계적 제거**
   - 안내: 가루화된 부식물만 조심스럽게 제거하세요.
   - 상태 기록: 금속심과 안정한 표면을 건드리지 않도록 확대 관찰하며 제거합니다.
   - 도구: 미세 제거 도구
3. **부식 안정화**
   - 안내: 계속 커지는 손상 부위에 안정화 처리를 하세요.
   - 상태 기록: 남은 염화물과 환경 위험을 살펴 손상이 더 번지지 않게 막습니다.
   - 도구: 부식 안정화 도구
4. **보호 코팅**
   - 안내: 얇고 균일한 보호층을 만들어 주세요.
   - 상태 기록: 두껍게 광택을 내지 않고 수분과 오염을 줄일 정도로만 바릅니다.
   - 도구: 보호 코팅
