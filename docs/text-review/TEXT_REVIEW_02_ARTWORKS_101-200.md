# 전체 텍스트 검수본 02 · 작품 101~200

각 작품의 화면 표시용 설명, 이야기, 손상, 복원 요약, 윤리 설명과 복원 단계를 담습니다.

### 101. 종이달의 궤도

- 작품 ID: `contemporary-07`
- 재질: 현대 복합재료
- 분류 문구: 특별 수장품
- 시대: 1980년대 혼합재료
- 작가: 현대미술가 김하진 (가상)
- 작품 종류: 복합재료·설치
- 어디서 왔나요?: 작가 작업실에서 오래 빌려 옴
- 작품 가치: 일상 재료의 새로운 의미와 작가의 설치 의도, 시간에 따라 변하는 작품 개념을 생각하게 합니다.
- 작품 이야기: 종이달의 궤도는 작가는 관람객이 남긴 짧은 메모를 작품의 다음 전시에 일부 반영해 매번 조금씩 다른 모습을 만들었습니다.
- 손상 설명: 서로 다른 재료를 붙인 부분이 벌어지고 표면도 여러 모습으로 변했습니다.
- 복원 완료 요약: 작가의 의도와 재료별 위험을 기록하고 원래 조립 방식을 해치지 않는 나중에 떼어 낼 수 있는 받침을 적용했습니다.
- 복원 윤리 설명: 현대 작품은 작가의 의도와 교체 가능한 요소를 확인하는 기록이 처리만큼 중요합니다.
- 가상 작품 여부: 게임을 위해 만든 가상 작품

#### 복원 단계

1. **재료 지도 작성**
   - 안내: 서로 다른 재료와 접합 방식을 표시하세요.
   - 상태 기록: 원래 조립, 노화, 의도된 변화 가능성을 나누어 기록합니다.
   - 도구: 확대경
2. **작은 범위 반응 시험**
   - 안내: 재료별로 안전한 접촉 범위를 확인하세요.
   - 상태 기록: 플라스틱, 종이, 도료가 서로 다르게 반응하는지 비교합니다.
   - 도구: 작은 시험용 면봉
3. **재료 사이 보호막 마련**
   - 안내: 서로 영향을 주는 재료 사이를 분리하세요.
   - 상태 기록: 원래 겉모양을 바꾸지 않는 나중에 걷어 낼 수 있는 얇은 보호층을 적용합니다.
   - 도구: 재료 사이 보호막
4. **전시 지지**
   - 안내: 무게가 접합부에 몰리지 않도록 받쳐 주세요.
   - 상태 기록: 작품의 설치 의도를 유지하며 무게를 여러 곳으로 나눕니다.
   - 도구: 작품 맞춤 받침

### 102. 대나무 숲 경판

- 작품 ID: `wood-07`
- 재질: 목제 유물
- 분류 문구: 희귀 기록
- 시대: 19세기 생활목기
- 작가: 목공예가 최해원 (가상)
- 작품 종류: 새기고 짜 맞춰 만든 나무 유물
- 어디서 왔나요?: 솔바람 목공소 기증
- 작품 가치: 나뭇결과 나무를 짜 맞추는 방법, 칼자국을 통해 재료 선택과 손도구 기술, 생활 속 쓰임을 읽을 수 있습니다.
- 작품 이야기: 대나무 숲 경판은 한 그루에서 나온 나무로 여러 물건을 만든 공방의 마지막 작품으로, 바닥에 같은 나이테 표시가 남아 있습니다.
- 손상 설명: 마르며 뒤틀린 곳, 표면이 떨어진 곳, 약한 이음부가 확인됩니다.
- 복원 완료 요약: 목재의 변형과 표면 흔적을 기록하고 환경 변화와 전시 무게를 줄이는 지지를 마련했습니다.
- 복원 윤리 설명: 목재의 갈라짐을 억지로 닫지 않고 현재 형태에 맞는 안정적인 환경과 지지를 우선합니다.
- 가상 작품 여부: 게임을 위해 만든 가상 작품

#### 복원 단계

1. **목리 조사**
   - 안내: 갈라짐과 벌레 먹은 흔적, 이음부를 살펴보세요.
   - 상태 기록: 제작 흔적과 계속 커지는 손상을 구분해 기록합니다.
   - 도구: 확대경
2. **표면 정리**
   - 안내: 표면이 떨어지는 현상을 피해 느슨한 먼지만 제거하세요.
   - 상태 기록: 도구 자국과 남은 채색을 보존합니다.
   - 도구: 부드러운 붓
3. **환경 적응**
   - 안내: 변형된 목재에 습도 변화가 급하지 않게 조절하세요.
   - 상태 기록: 직접 수분을 가하지 않고 완만한 환경을 만듭니다.
   - 도구: 직접 물이 닿지 않는 가습 팩
4. **형태 지지**
   - 안내: 현재 형태에 맞춰 무게를 여러 곳으로 나누세요.
   - 상태 기록: 갈라짐을 강제로 닫지 않는 맞춤 받침을 사용합니다.
   - 도구: 작품 맞춤 받침

### 103. 은하수 백자 잔

- 작품 ID: `ceramic-08`
- 재질: 도자기
- 분류 문구: 기증 컬렉션
- 시대: 20세기 초 공방작
- 작가: 도예가 이새벽 (가상)
- 작품 종류: 유약 장식 도자기
- 어디서 왔나요?: 해오름 도요 기증
- 작품 가치: 성형 흔적과 유약 흐름, 생활 도구가 예술품으로 변화한 과정을 함께 보여 줍니다.
- 작품 이야기: 은하수 백자 잔은 가마 문을 여는 날마다 색이 다르게 나타나 ‘한 번뿐인 빛’을 담은 그릇으로 불렸습니다.
- 손상 설명: 아주 가는 금과 오래전에 붙인 부분, 작은 빈 곳이 함께 보입니다.
- 복원 완료 요약: 표면과 구조를 조사한 뒤 이탈부를 안정화하고 빈 곳 범위만 구별 가능하게 보완했습니다.
- 복원 윤리 설명: 도자기의 사용 흔적과 제작 흔적은 지우지 않고, 구조 안전에 필요한 범위만 개입합니다.
- 가상 작품 여부: 게임을 위해 만든 가상 작품

#### 복원 단계

1. **금 지도 작성**
   - 안내: 빛을 비춰 금과 과거 접합 흔적을 찾으세요.
   - 상태 기록: 새 금과 안정된 제작 흔적을 구분해 기록합니다.
   - 도구: 확대경
2. **표면 반응 시험**
   - 안내: 장식이 안정적인 작은 지점을 확인하세요.
   - 상태 기록: 유약과 그림 물감이 처리에 반응하지 않는지 작은 범위 시험합니다.
   - 도구: 작은 시험용 면봉
3. **구조 안정화**
   - 안내: 이탈한 경계를 최소한으로 접합하세요.
   - 상태 기록: 재처리 가능성을 고려해 구조에 필요한 접합만 시행합니다.
   - 도구: 나중에 다시 뗄 수 있는 접착제
4. **빈 곳 보완**
   - 안내: 빈 비어 있는 부분 안에서만 형태를 연결하세요.
   - 상태 기록: 원본 표면을 덮지 않고 작은 빈 곳의 지지만 회복합니다.
   - 도구: 작은 틈 메움 주걱

### 104. 매화 아래 고양이

- 작품 ID: `paper-08`
- 재질: 종이·채색
- 분류 문구: 특별 수장품
- 시대: 1920년대 화첩
- 작가: 채색화가 백소담 (가상)
- 작품 종류: 종이 바탕 채색화
- 어디서 왔나요?: 다정헌 가문에서 맡김
- 작품 가치: 계절의 상징과 생활 속 소망을 섬세한 선과 색으로 기록한 시각 자료입니다.
- 작품 이야기: 매화 아래 고양이는 집안의 중요한 날마다 펼쳐 두었던 그림으로, 접힌 자국마다 가족 행사의 기억이 남아 있습니다.
- 손상 설명: 접힘과 가장자리 찢김, 채색층이 들뜬 곳이 관찰됩니다.
- 복원 완료 요약: 재료의 민감도를 확인하고 간접 가습과 얇은 지지로 종이의 변형과 찢김을 안정화했습니다.
- 복원 윤리 설명: 종이와 그림 물감마다 반응이 다르므로 전체 처리보다 색별 시험과 작은 범위 안정화를 우선합니다.
- 가상 작품 여부: 게임을 위해 만든 가상 작품

#### 복원 단계

1. **재료 조사**
   - 안내: 번짐과 들뜸 가능성이 있는 부분을 찾으세요.
   - 상태 기록: 종이 섬유, 채색, 과거 보수 흔적을 나누어 기록합니다.
   - 도구: 확대경
2. **색 묻어남 시험**
   - 안내: 색마다 작은 시험 지점을 확인하세요.
   - 상태 기록: 수분에 민감한 채색이 묻어나지 않는지 확인합니다.
   - 도구: 작은 시험용 면봉
3. **휘어진 곳 펴기**
   - 안내: 접힌 부분에 습도를 천천히 전달하세요.
   - 상태 기록: 직접 물을 대지 않고 휘어진 곳을 천천히 폅니다.
   - 도구: 직접 물이 닿지 않는 가습 팩
4. **찢김 지지**
   - 안내: 찢어진 가장자리를 뒤에서 받쳐 주세요.
   - 상태 기록: 얇은 보존용 지지로 당기는 힘을 여러 곳으로 나누고 원본을 가리지 않습니다.
   - 도구: 보존용 종이

### 105. 언덕 위 붉은 집

- 작품 ID: `painting-08`
- 재질: 유화
- 분류 문구: 희귀 기록
- 시대: 1930년대 도시회화
- 작가: 화가 임윤호 (가상)
- 작품 종류: 캔버스 유채
- 어디서 왔나요?: 은하 미술연구회 기증
- 작품 가치: 빛과 색을 다루는 시대별 그리는 방법과 도시 생활의 변화를 한 화면에서 읽을 수 있습니다.
- 작품 이야기: 언덕 위 붉은 집은 작가는 같은 장소를 여러 계절에 그렸고, 이 작품의 뒷면에는 다음 그림을 위한 작은 색 메모가 남아 있습니다.
- 손상 설명: 먼지층과 누렇게 변한 코팅, 채색층이 조금 들뜬 곳이 보입니다.
- 복원 완료 요약: 층위를 조사하고 안전한 시험 자리를 기준으로 먼지와 변색층을 작은 범위만 줄였습니다.
- 복원 윤리 설명: 표면의 세월을 모두 제거하지 않고, 원래 채색층이 안전한 범위에서만 다시 알아보기 쉽게 합니다.
- 가상 작품 여부: 게임을 위해 만든 가상 작품

#### 복원 단계

1. **층위 조사**
   - 안내: 코팅과 채색층의 경계를 살펴보세요.
   - 상태 기록: 광택, 금, 과거 덧칠을 구분해 처리 범위를 정합니다.
   - 도구: 확대경
2. **세척 시험**
   - 안내: 색 변화가 가장 적은 시험 자리를 찾으세요.
   - 상태 기록: 작은 시험창에서 그림 물감과 광택의 안정성을 비교합니다.
   - 도구: 작은 시험용 면봉
3. **표면 먼지 제거**
   - 안내: 들뜬 채색을 피해 먼지만 걷어내세요.
   - 상태 기록: 불안정한 부분을 건드리지 않고 느슨한 오염만 제거합니다.
   - 도구: 부드러운 붓
4. **변색층 조정**
   - 안내: 시험을 마친 범위만 천천히 처리하세요.
   - 상태 기록: 전체 제거가 아닌 작은 범위 단위로 반응을 확인합니다.
   - 도구: 오염 제거 겔
5. **빈 곳 복원한 곳의 색 맞추기**
   - 안내: 작은 빈 곳 안에서만 색을 연결하세요.
   - 상태 기록: 가까이에서는 복원한 곳을 구별할 수 있도록 필요한 부분만 색을 맞춥니다.
   - 도구: 복원 색 붓

### 106. 해와 달 금동판

- 작품 ID: `metal-08`
- 재질: 금속
- 분류 문구: 새 발견
- 시대: 1910년대 공방작
- 작가: 금속공예가 박도윤 (가상)
- 작품 종류: 쇳물을 틀에 붓거나 두드려 만든 금속 공예
- 어디서 왔나요?: 별고을 생활사관에서 옮겨 받음
- 작품 가치: 주조와 두드림 자국, 여러 금속을 섞은 재료 표면의 변화가 당시의 기술과 사용 방식을 전합니다.
- 작품 이야기: 해와 달 금동판은 오랫동안 한 가족의 기념일에만 꺼내 쓰던 물건으로, 가장자리의 작은 닳음이 사용 순서를 알려 줍니다.
- 손상 설명: 가루처럼 약해진 녹과 더 번지지 않는 녹슨 표면이 함께 남아 있습니다.
- 복원 완료 요약: 계속 번지는 녹과 안정한 표면을 구분하고 계속 커지는 손상만 늦춘 뒤 얇은 보호층을 적용했습니다.
- 복원 윤리 설명: 금속을 새것처럼 빛내기보다 안정된 표면과 역사적 흔적을 남기는 것이 우선입니다.
- 가상 작품 여부: 게임을 위해 만든 가상 작품

#### 복원 단계

1. **부식 조사**
   - 안내: 가루화와 들뜸이 있는 지점을 찾으세요.
   - 상태 기록: 안정한 녹과 진행 중인 부식을 형태와 상태로 구분합니다.
   - 도구: 확대경
2. **불안정층 제거**
   - 안내: 가루화된 부식물만 조심스럽게 덜어내세요.
   - 상태 기록: 금속심과 안정한 표면을 건드리지 않도록 확대 관찰합니다.
   - 도구: 미세 제거 도구
