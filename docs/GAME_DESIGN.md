# 게임 기획서 — 반짝! 복원 미술관

## 1. 한 줄 소개

다양한 재료의 미술품을 올바른 순서와 도구로 복원하고, 되살린 작품을 전시해 작은 미술관을 성장시키는 밝고 캐주얼한 HTML5 경영 게임.

## 2. 핵심 경험

1. **전후 변화의 만족감**: 손상된 작품이 단계마다 깨끗하고 안정적인 모습으로 변한다.
2. **재료별 복원법의 차이**: 도자기, 종이, 회화, 금속이 서로 다른 판단과 도구를 요구한다.
3. **복원과 운영의 연결**: 복원 결과가 전시 매력도, 관람객, 수입, 평판으로 이어진다.
4. **최소 개입의 선택**: 무조건 닦고 채우는 대신 조사·시험·안정화·기록을 중시한다.

## 3. 타깃

- 10대 후반~30대 캐주얼·힐링 게임 이용자
- 꾸미기, 수집, 정리, 복구, 전후 비교 콘텐츠를 좋아하는 이용자
- PC·태블릿·모바일 브라우저에서 5~15분 단위로 플레이

## 4. 코어 루프

긴급 관장 취임 → 봉인된 기록 확인 → 비서 브리핑 → 보존 연습 또는 수장고에서 작품 선택 → 작품 이야기 확인 → 손상 조사 → 안전성 시험 → 재료별 복원 미니게임 → 정확도·완료 시간 보상 → 처리 기록 작성 → 전시 배치 → 관람객 코멘트·수입 획득 → 매력도 100 스토리 → 시설 투자와 공간 확장 → 새로운 작품 해금

새 게임에서는 위 흐름의 첫 번째 로테이션 전체를 윤슬의 10단계 상황별 가이드로 진행한다. 현재 눌러야 할 요소를 강조하고, 각 미니게임의 목표와 실패 후 재시도 방법을 설명하며, 전시 개관과 운영 보고까지 완료하면 자유 운영으로 전환한다.

### 정확도와 재투자

- 정확도 80%부터 B 등급 보너스가 시작되며 90% A, 95% S, 100% S+로 상승한다.
- 정확도 보너스는 기존 정확도 비례 지원금과 별도로 지급해 능숙한 플레이의 차이를 분명히 만든다.
- S 이상은 추가 평판도 지급하고 결과 화면과 처리 기록에 등급·보너스를 남긴다.
- 복원 시작부터 완료까지 실제 조작 시간을 재며, 다른 메뉴·도움말·브라우저 백그라운드에서는 시간을 멈춘다. 정확도 80% 이상일 때만 완료 시간에 따라 100·200·300점과 코인 보너스를 준다.
- 기술 점수는 `정확도 × 100 + 시간 가산점`이며 기록실에 완료 시간과 함께 남는다.
- 첫 개관 수입이 생긴 뒤 시설 투자가 열리며, 시설은 보유 코인으로 구매한다. 기본 시설 12개는 매력도, 관람객, 개관 수입, 평판, 복원 위험, 복원 지원금, 전시 슬롯을 서로 다르게 강화한다.
- 15일차에는 각 기본 시설을 한 번 더 발전시키는 2단계 개선 12개가 열린다. 총 42,200코인이 필요한 후기 투자로 수입의 장기 사용처를 만든다.
- 설치·개선된 시설은 아이콘 상자가 아니라 조명 트랙·해설 키오스크·아트숍·환경 관제판·환기구·라운지·기록 서가·조각 정원·카페·복원 스튜디오·파사드·기둥과 샹들리에의 색, 조명, 장식, 표지판이 전시장과 편의동에서 직접 달라진다.
- 후반 파사드와 대전시홀은 전시 슬롯을 4칸에서 최대 6칸으로 늘리고 전시관 구조 자체를 바꾼다.

### 보존 연습

- 14종 조작을 카드에서 직접 골라 한 종씩 반복할 수 있다.
- 연습 점수는 기술별 최고 정확도만 저장한다.
- 연습은 재료비, 코인, 평판, 실제 작품의 복원 기록을 바꾸지 않는다.
- 실제 복원 도중 연습실을 다녀와도 원래 작품 세션을 복구한다.

### 리듬 게임 레퍼런스 적용 원칙

- 닌텐도 `Rhythm Heaven Groove`의 공식 소개가 강조하는 `배우기 쉽지만 숙달할수록 보상이 커지는 짧은 규칙`, `소리와 시각 신호로 다음 입력을 예고`, `즉시 판정`을 참고한다.
- 그림·음악·고유 게임 규칙을 복제하지 않고, 복원 행동 하나를 짧고 읽기 쉬운 입력으로 번역하는 구조만 차용한다.
- 접착제 점적은 `1 → 2 → TAP` 예고와 수축 원을 결합하고 PERFECT/GOOD/EARLY/LATE를 바로 보여 준다.

## 6. 확장 콘텐츠 우선순위

### 우선순위 A — 수상용 완성도

- 작품마다 14종 중 도구와 단계 목적에 맞는 4~5종을 우선 배정한다. 난이도는 카탈로그 순서가 아니라 민감한 도구 수와 손상 복합도로 산정한다.
- 한 입력을 반복하지 않는다. 탭은 손상 기록, 가습 상태 전환, 상황 카드 선택, 수축 원 점적처럼 서로 다른 결과를 만들고, 홀드·놓기는 미세량 조절에만 사용한다.
- 실패 피드백은 단순한 ‘틀림’ 대신 제작 흔적 오인, 과습, 과다 충전, 접착제 넘침처럼 실제 복원 판단의 결과로 설명한다.
- 전문 용어는 정식 작업명으로 남기되 바로 아래에 `쉽게 말하면`과 `작품 변화`를 표시한다. 조작법뿐 아니라 그 처리가 원본 색, 섬유, 균열, 접합부에 어떤 도움을 주는지 일상어로 설명한다.
- 첫 작품은 손상 조사 → 시험구 판정 → 최소량 접착제 점적 → 미세 충전 → 식별 가능한 보색 순서로 구성해 1회 로테이션 안에서 이동·관찰·타이밍·홀드·형태 비교를 학습한다.
- 첫 10분 튜토리얼의 컷신·표정·대사 연출 확장
- 복원 전/후 슬라이더와 확대 관찰 카메라
- 실존 작품을 사용할 경우 출처·저작권·사실관계 검수
- 작품별 고유 일러스트와 복원 단계별 손상 레이어 제작

### 우선순위 B — 운영 재미

- 전시 테마와 작품 조합 보너스
- 관람객 유형: 가족, 학생, 연구자, 관광객
- 교육 프로그램, 특별전, 굿즈 기획
- 환경 관리: 조도, 온습도, 혼잡도
- 미술관 확장과 공간 꾸미기

### 우선순위 C — 장기 플레이

- 주간 의뢰, 컬렉션 도감, 희귀 작품
- 도전 모드: 제한 시간, 제한 예산, 불완전한 진단 정보
- 시즌 전시와 이벤트
- 클라우드 저장 및 계정 연동

## 7. 아트 디렉션

- 키워드: 밝음, 캐주얼, 말랑함, 입체감, 수집욕, 복원 전후 대비
- 형태: 둥근 실루엣, 큰 하이라이트, 굵고 부드러운 외곽선
- 표면: 플라스틱·도자기 장난감처럼 매끈한 그라데이션과 소프트 섀도
- 색: 크림, 코랄, 살구, 민트, 하늘, 금빛을 중심으로 고채도 포인트
- UI: 둥근 카드, 도톰한 버튼, 흰색 인셋 하이라이트, 8~18px 낙하 그림자
- 피해야 할 것: 사실적인 오염·상처의 혐오감, 어두운 창고, 과도한 텍스트, 강한 화학실 이미지

## 8. 교육성과 재미의 균형

- 실제 보존처리의 원칙을 그대로 시험 문제처럼 만들지 않는다.
- 매 단계에서 핵심 판단 1개만 게임 규칙으로 바꾼다.
- 전문 화학물질의 배합·농도는 직접 조작시키지 않는다.
- 오답은 작품 파괴보다 위험도·보상 감소로 표현한다.
- 완료 화면에서 1문장 윤리 노트로 실제 원칙을 전달한다.

## 9. 기술 방향

- 현재: Vanilla HTML/CSS/JavaScript, 인라인 SVG, localStorage
- 관장 이름과 미술관 이름은 첫 취임식과 윤슬의 명패 수정 창에서 바꿀 수 있다. 허용 문자·길이·반복 문자·욕설·혐오·범죄 조장 표현·연락처를 저장 전과 저장 불러오기 때 검사한다.
- 온라인 랭킹은 `docs/ONLINE_RANKING.md`의 Google Apps Script 시험안과 Cloudflare Worker+D1 공개안으로 분리해 설계한다. 백엔드가 없는 현재 빌드는 로컬 기록만 사용한다.
- 수상 제출 권장: Vite + TypeScript로 이전, 데이터/렌더/UI 분리
- 아트 확장: SVG 또는 WebP 스프라이트 + CSS/Canvas 파티클
- 사운드: 최초 버전의 실시간 생성 Web Audio BGM + 자체 생성 WAV·Web Audio 이중 효과음. WAV BGM은 폴백으로 유지하며, 추후 라이선스 확인된 OGG/MP3로 교체 가능
- 배포: 정적 호스팅, 전체 화면 반응형, 오프라인 캐시 선택 적용

## 10. 완료 기준

- 첫 실행부터 첫 작품 복원까지 3분 이내
- 한 작품당 2~5분, 숙련자는 165초 이내 금 시간 보너스 도전
- 터치와 마우스 모두 오동작 없이 완주
- 새로고침 후 진행 보존
- 360px 모바일과 1440px PC에서 핵심 UI가 잘리지 않음
