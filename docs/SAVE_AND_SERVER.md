# 저장과 서버 연결 가이드

## 현재 버전: API 없이 동작

- 자동 저장: 브라우저 `localStorage`
- 수동 백업: 기록실의 **저장 파일 받기**
- 다른 기기에서 복원: 기록실의 **저장 파일 불러오기**
- 게임 실행과 저장 모두 정적 파일만으로 가능

이 방식은 계정과 서버가 없어도 작동하고 운영 비용이 없습니다. 다만 브라우저 데이터 삭제, 시크릿 모드, 기기 분실 때 자동 저장은 함께 사라질 수 있으므로 중요한 진행은 JSON 파일로 백업하는 편이 안전합니다.

## API가 필요한 경우

다음 기능이 필요할 때는 브라우저와 원격 저장소가 통신하는 API 또는 같은 역할을 하는 백엔드 서비스가 필요합니다.

- 여러 기기 사이 자동 동기화
- 로그인 계정별 클라우드 저장
- 랭킹, 친구, 공동 이벤트
- 운영자가 추가하는 새 콘텐츠
- 부정 조작 검증과 결제 기록

직접 서버 API를 만들지 않고 Firebase, Supabase 같은 관리형 서비스를 붙일 수도 있지만, 내부적으로는 해당 서비스의 API를 사용합니다.

## 권장 순서

1. 현재의 `localStorage` + JSON 백업으로 게임성과 콘텐츠를 완성합니다.
2. 저장 데이터에 버전 번호와 마이그레이션 규칙을 확정합니다.
3. 계정·동기화가 실제로 필요해질 때 인증과 클라우드 저장을 추가합니다.

현재 저장 키 `sparkle_restoration_museum_v1`과 기존 저장 형태는 유지됩니다.
