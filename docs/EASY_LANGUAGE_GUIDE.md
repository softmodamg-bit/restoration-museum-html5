# 쉬운말 문구 기준

이 게임은 초등학생 이상이 혼자 읽고 플레이할 수 있도록 다음 순서를 지킨다.

1. 화면에서 가장 먼저 보이는 제목은 플레이어가 지금 할 행동으로 쓴다.
2. 실제 보존 용어는 없애지 않고 `배우는 복원 용어` 아래에 따로 남긴다.
3. 설명은 `지금 할 일 → 왜 할까요? → 작품에 좋은 점` 순서로 쓴다.
4. 한 문장에는 한 가지 판단이나 행동만 넣는다.
5. 버튼은 명사보다 `고르기`, `멈추기`, `다시 보기`, `수입 받기`처럼 행동으로 쓴다.
6. 실패 문구는 잘못을 나무라지 않고, 무엇을 다시 보면 되는지 알려 준다.
7. 색만 설명하지 않고 모양, 테두리, 질감 같은 단서도 함께 말한다.
8. 작품명, 작가명, 시대명, 실제 재질명처럼 학습에 필요한 고유 정보는 바꾸지 않는다.
9. 이야기 순서는 `PROLOGUE`, `CHAPTER`, `ENDING` 대신 `처음 이야기`, `이야기 1`, `마지막 이야기`처럼 바로 이해되는 말로 표시한다.
10. 쉬운말 사전의 정식·어려운 표현은 검색과 학습을 위해 그대로 둔다. 화면 치환 뒤의 조사는 새 표현의 받침에 맞춰 자동으로 바뀌고, 같은 표현이 연속되면 하나로 합쳐진다.

## 미니게임 제목 기준

| 먼저 보이는 쉬운 제목 | 배우는 복원 용어 |
| --- | --- |
| 옆빛으로 손상 찾기 | 사광 손상 조사 |
| 작은 시험 결과 고르기 | 시험구 안전 판정 |
| 결을 따라 먼지 털기 | 결 따라 표면 정리 |
| 붙이기 전 조각 맞춤 | 파편 가접합 |
| 온도·습도 안전하게 맞추기 | 환경 안정화 조절 |
| 알맞은 양에서 손 떼기 | 미세량 홀드 조절 |
| 안전한 다음 행동 고르기 | 처리 절차 판단 |
| 접착제 한 방울 맞추기 | 접착제 점적 타이밍 |
| 구별되는 복원 색 고르기 | 식별 가능한 보색 |
| 금과 무늬 이어 맞추기 | 접합면 방향 정렬 |
| 오염을 걷고 멈출 때 고르기 | 세척 강도 판단 |
| 자외선으로 옛 수리 흔적 찾기 | 자외선 형광 조사 |

## 자주 바꾸는 표현

| 어려운 표현 | 먼저 보여 줄 쉬운 표현 |
| --- | --- |
| 시험구 | 시험 자리 |
| 사광 | 옆에서 비추는 빛 |
| 안료 이동 | 그림 물감 묻어남 |
| 결손 | 빈 곳 |
| 박락 | 표면이 떨어지는 현상 |
| 분말화 | 가루처럼 약해지는 현상 |
| 국부 처리 | 작은 범위만 처리 |
| 접합면 | 조각이 맞닿는 면 |
| 가역 재료 | 나중에 다시 떼거나 걷어 낼 수 있는 재료 |
| 이염 | 색 묻어남 |
| 보색 | 복원한 곳의 색 맞추기 |
| 점적 | 한 방울 떨어뜨리기 |
| 후대 보수 | 과거에 고친 흔적 |
| 형광 반응 | 자외선에서 다르게 빛나는 모습 |

새 문구를 추가한 뒤에는 `node scripts/test-easy-language.mjs`를 실행한다. 조사 교정은 치환된 표현 바로 뒤에서만 작동하므로, 사전의 쉬운 표현 끝에는 조사를 미리 붙이지 않는 것을 원칙으로 한다. 단, `안료와 → 그림 물감과`처럼 문맥 전체를 고정해서 바꾸는 기존 항목은 구체적인 항목을 일반 항목보다 앞에 둔다.
